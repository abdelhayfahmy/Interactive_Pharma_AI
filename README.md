A comprehensive, interactive Single-Page Application (SPA) designed to upskill pharmaceutical operations teams in deploying and utilizing Enterprise AI tools. This portal bridges the gap between theoretical AI concepts and practical, compliant execution in highly regulated healthcare environments.

## 🌟 Key Features

* **5 Core Interactive Modules:** Step-by-step UI walkthroughs covering Microsoft 365 Copilot, Zendesk AI, Route4Me, Azure IoT Central, and Power BI Copilot.
* **Scenario-Based Learning:** Branching operational dilemmas requiring users to make compliance-driven and efficiency-focused decisions.
* **Dynamic Assessment Engine:** Built-in baseline pre-assessment and a rigorous 80%-benchmark post-assessment to guarantee knowledge retention (Kirkpatrick Level 2).
* **Automated Data Collection:** Seamless Google Sheets API integration for real-time submission of trainee scores, registration data, and Level 1 survey feedback.
* **Anti-Theft Protection:** Implemented UI and JavaScript obfuscation layers to prevent unauthorized code inspection, text copying, and media scraping.
* **Zero-Setup Execution:** Fully contained HTML/CSS/JS architecture with embedded `youtube-nocookie` video iframes—no external local assets or databases required.

## 🚀 Deployment Instructions (GitHub Pages)

This portal is designed to run flawlessly on GitHub Pages without any backend server configuration.

1. Create a new repository on GitHub.
2. Upload the `index.html` file to the root of the repository.
3. Go to the repository **Settings** > **Pages**.
4. Under "Build and deployment", set the source to **Deploy from a branch**.
5. Select the `main` branch and `/root` folder, then click **Save**.
6. GitHub will generate a live URL (e.g., `https://[your-username].github.io/[repo-name]/`) within 1-2 minutes.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Custom Corporate Design System), Vanilla JavaScript (ES6+).
* **Media:** YouTube Iframe API (`strict-origin-when-cross-origin` policy).
* **Backend Integration:** Google Apps Script (Google Sheets Webhook for data collection).
* **Security:** JavaScript Event Listeners (Context Menu/Keystroke blocking) & Code Obfuscation.
